## Recording decisions

Add a dated entry under this directory when a decision or interface needs more detail than the README can carry. Distinguish **decided behavior**, **proposals**, and **verified deployment observations**. For an observation, include the host, date and evidence; for a proposal, identify the open choice. Keep credentials, private keys and live secret values out of Git.

Keep the root README as the entry point; retain implementation, configuration and runbooks in their existing directories. A historical proposal does not by itself prove a running deployment.
